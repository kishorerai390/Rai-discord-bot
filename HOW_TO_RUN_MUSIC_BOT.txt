           🎵 MUSICMAID — DISCORD MUSIC BOT & WEB PLATFORM
============================================================

Quick 3-Step Setup Guide:

1. INSTALL DEPENDENCIES:
   Open terminal in this folder and run:
   pip install -r requirements.txt

2. CONFIGURE YOUR BOT TOKEN:
   - Copy ".env.example" to ".env"
   - Go to Discord Developer Portal: https://discord.com/developers/applications
   - Select your bot -> "Bot" tab -> Copy your Bot Token
   - Under "Privileged Gateway Intents", enable:
     [x] Message Content Intent
     [x] Server Members Intent
   - In your ".env" file, set:
     MUSIC_BOT_TOKEN=your_token_here

3. INVITE BOT TO YOUR SERVER:
   https://discord.com/oauth2/authorize?client_id=1554626865958887444&permissions=2268449856&scope=bot%20applications.commands

4. RUN THE BOT & WEB PLATFORM:
   python main.py
   (or: npm start)

✦ Web Player & Dashboard will be live at: http://localhost:8080/music
✦ Health check endpoint will be live at: http://localhost:8080/health

============================================================
Key Music Commands:
- /play <query/url> : Play from YouTube, Spotify, SoundCloud, Bandcamp
- /c : Interactive Master Control Panel & 13-button UI
- /filter : Bass Boost, Nightcore, 8D Audio, Vaporwave, Vocal
- /247 or /stay : Stay in voice channel 24/7 with auto-reconnect
- /radio <mood> : 24/7 Continuous Vibe Radio (chill, gaming, lofi, etc.)
- /sleeptimer <mins> : Sleep timer with smooth volume fade-out
- /playlist : Save, load, list, and delete server queues
- /music dj : Smart Auto-DJ recommendations
- /music lyrics : Synchronized real-time lyrics
